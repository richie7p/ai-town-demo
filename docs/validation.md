## 瀏覽器操作

以 Microsoft Edge／Playwright 在 1440px 桌面與 390px 手機寬度檢查。通過以下操作：

- 八位角色顯示、點選及決策檢視。
- 逐步推進、自動播放、暫停。
- 背景跑完十日，完成後才顯示主指標 Y。
- 回放至過去時段時，顯示當時觀察、記憶、指標與事件。
- 事件篩選、條件切換並重新建立場次。
- 歷史回放中匯出，仍保存全部已執行時段。
- JSON 載入後，完整重播驗證通過且指標相同。
- 修改事件文字後匯入被拒絕，原有場次不被覆寫。
- 同種子 A8/B2 比較，不覆蓋當前世界。
- 手機無水平溢出；未發現瀏覽器主控台錯誤。
