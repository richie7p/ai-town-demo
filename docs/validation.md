- Phaser WebGL 正常啟動；原創家具、四個房間、48 幀人物素材載入未產生主控台錯誤。

- 在床邊按左鍵被床擋住，位置不變；按 E 能查看身旁床鋪；關閉資訊後鍵盤焦點回到地圖。
- 設定表單取得焦點後按方向鍵，訪客位置不變。
- 居民開始、暫停、恢復與快速連按逐步正常；恢復時不跳過當前時段。
- 完成十日顯示 120／120；回到 0 時事件清空、最終指標隱藏。回到第 31 時段，可見小苒與知序在同一張工作桌完成合作。

## 瀏覽器操作

以 Microsoft Edge／Playwright 在 1440px 桌面與 390px 手機寬度檢查。通過以下操作：

- 八位角色顯示、點選及決策檢視。
- 逐步推進、自動播放、暫停。
- 背景跑完十日，完成後才顯示主指標 Y。
- 回放至過去時段時，顯示當時觀察、記憶、指標與事件。
- 事件篩選、條件切換並重新建立場次。
- 歷史回放中匯出，仍保存全部已執行時段。
- JSON 載入後，完整重播驗證通過且指標相同。
- 修改事件文字後匯入被拒絕，原有場次不被覆寫。
- 同種子 A8/B2 比較，不覆蓋當前世界。
- 手機無水平溢出；未發現瀏覽器主控台錯誤。

這些驗證不涵蓋尚未實作的真實模型、服務重試、費用記帳、反思、正式抽樣或統計推論。

## v0.2 生活介面重製（2026-11-04）

依 V5 原版重製展示，世界引擎與回放格式維持原版。此輪完整引擎／策略／伺服器測試 25 項通過，另新增並通過 3 項 Canvas 回歸測試，共 28 項。Canvas 測試包含 DPR 1 背景初始化、完整 121 幀資料不變性、成功對話與失敗提議的區分，以及含留白／DPR 2 的人物點選映射。

透過 Codex 內嵌瀏覽器，以 1365 × 1000 桌面和 390 × 844 手機尺寸實際檢查：

- 開始、自動播放、暫停、逐步、居民切換，以及決策前記憶來源。
- 完成十日後仍能從頭回放；拖回第零時段時互動數歸零、最終 Y 不顯示。
- 互動來源能追溯到 D1，不受 viewFrame 的最近 180 筆限制。
- 完整 120 時段 JSON 匯出後重新載入，驗證成功並停在開頭等待播放。
- 合法紀錄中的無效目的地提議能回放，顯示失敗原因，不中斷畫面。
- A8/B2 配對比較保留目前場次；設定 A8 並確認後建立全新場次。
- 手機頁面沒有水平溢出，離線／非 LLM 標示仍可見。
- 瀏覽器未記錄 JavaScript 錯誤。桌面預覽保存在 demo-v0.2-preview.jpg。

對話移動動畫使用播放間隔的 45%，其餘時間保留泡泡閱讀。地圖站位與動畫只作展示，不改寫研究世界。

內嵌瀏覽器此次未授權 Fullscreen API，介面已顯示可繼續操作的提示；不能宣稱已在此環境驗證全螢幕實際展開。人物點選的 contain 留白計算有自動化回歸測試。

## v0.4 街區與人物美術重製（2026-11-04）

以新背景美術和 64×96 人物素材替換 v0.3 的簡化地景。展示世界 2400×1600，背景原圖實際為 1536×1024；鏡頭使用獨立 1200×800 邏輯畫面。來源與完整提示詞見 `art-direction-v0.4.md`。

完整 `npm test` 33 項通過，包含新增的噴泉外環跨區路徑不穿水池測試與背景 PNG 的受限公開路由。世界引擎、策略、記憶、統計指標及回放格式沒有改動。另以真正 Canvas runtime 檢查 240 個人物幀、紋理重用、人物資料不可變性及換 ID 後 persona 外觀穩定。

內嵌瀏覽器驗證：

- WebGL 正常載入新圖片與人物，四個街區捷徑、全鎮視角、縮圖導航、縮放與頁內放大均可操作。
- 桌面 1440px 及手機 390px；手機頁面寬度 375px，沒有水平溢出，離線示範標示仍可見。
- 暫停後續播維持當前時段，先完成當前過場；快速逐步會完成前一個展示終點再計算路線。
- 舊版完整 120 時段 JSON 在新美術下成功驗證載入；畫面維持已保存的事件與行動。
- 同時保留角色的名字、服裝與側欄頭像一致性；所有泡泡仍只取當步成功事件。

整合時圖片預設 XHR blob 流程被既有圖片來源限制阻擋，已改用 Phaser 支援的 HTMLImageElement 同來源載入方式，未放寬 CSP。修正後操作未產生新的 JavaScript 錯誤。
